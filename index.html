01Retrieval infrastructure2026

Tana Semantic Engine

A cloud-hosted semantic layer for a Tana knowledge graph. It gives AI clients a way to search by meaning, then use Tana’s native graph to recover hierarchy, references, tags and fields.

Problem

Pure keyword search misses meaning. Pure vector search loses structure.

Approach

Blend dense retrieval, BM25, graph expansion, temporal provenance and multi-factor reranking.

Delivery

OpenAPI, MCP and REST interfaces, with serverless Cloudflare deployment and automated sync.

02AI evaluation2026

Drift Detector

A lightweight early-warning system for long AI coding sessions. It tracks semantic departure from an on-task baseline and only raises the alarm when divergence persists.

  • Vector-distance monitoring instead of a second LLM judging every turn
  • Page-Hinkley trend gating to forgive isolated tangents
  • Original mission anchor preserved across context compaction
  • Local and hosted embedding providers plus deterministic test mode

How I work

Technical curiosity, with a bias towards things that actually run.

I came into AI from physics, so I naturally think in terms of signals, models, failure modes and measurement. I’m most interested in the unglamorous layer between a capable model and a dependable product: retrieval, context, interfaces, evaluation and system behaviour over time.

I’m early in my professional AI career, but I’m comfortable taking an idea from rough problem statement to architecture, prototype, deployment and documented demo. I care about explaining what a system does, where it fails and why the chosen design is proportionate.
